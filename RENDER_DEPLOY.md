# Быстрый деплой на Render (РЕКОМЕНДУЕТСЯ)

Render - лучший вариант для Flask приложений. Это займет 5 минут!

## Шаг 1: Подготовка

Убедитесь, что все файлы загружены в GitHub:
- ✅ `app.py`
- ✅ `poker_tracker.py`
- ✅ `requirements.txt`
- ✅ `Procfile`
- ✅ `templates/` и `static/`

## Шаг 2: Деплой на Render

1. Перейдите на [render.com](https://render.com)
2. Нажмите **"Get Started for Free"** и зарегистрируйтесь (можно через GitHub)
3. В Dashboard нажмите **"New +"** → **"Web Service"**
4. Подключите ваш GitHub репозиторий:
   - Нажмите **"Connect account"** если еще не подключен
   - Выберите репозиторий `poker-tracker` (или как вы назвали)
5. Настройки деплоя:
   - **Name:** `poker-tracker` (или любое другое)
   - **Region:** Выберите ближайший (например, Frankfurt)
   - **Branch:** `main`
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app`
6. Нажмите **"Create Web Service"**
7. Дождитесь завершения деплоя (2-3 минуты)

## Шаг 3: Проверка

После деплоя Render предоставит URL вида: `https://poker-tracker.onrender.com`

Откройте его в браузере и проверьте:
- ✅ Приложение загружается
- ✅ Можно добавить игрока
- ✅ Статистика работает
- ✅ Темная тема работает

## Обновление приложения

После каждого `git push` Render автоматически пересоберет и задеплоит новую версию!

## Преимущества Render

- ✅ Бесплатный тариф (достаточно для начала)
- ✅ Отличная поддержка Python/Flask
- ✅ Автоматический деплой из GitHub
- ✅ HTTPS из коробки
- ✅ Простая настройка

## Решение проблем

Если деплой не удался:
1. Проверьте логи в Render Dashboard
2. Убедитесь, что `requirements.txt` содержит все зависимости
3. Проверьте, что `Procfile` правильный
4. Убедитесь, что все файлы в репозитории

## База данных

⚠️ **Важно:** SQLite файл на Render может быть эфемерным (удаляется при перезапуске).

Для постоянного хранения:
1. Используйте Render PostgreSQL (платно)
2. Или используйте внешнюю БД
3. Или используйте Railway/Render с постоянным хранилищем

Но для тестирования и небольших проектов SQLite на Render работает нормально.
