# Исправление ошибки деплоя на Netlify

## Проблема
Netlify пытается установить npm зависимости, но проект на Python.

## Решение

Я обновил конфигурацию:

1. **Создан `package.json`** - пустой файл для Netlify (чтобы не было ошибок npm)
2. **Обновлен `netlify.toml`** - упрощена команда сборки
3. **Создан `.nvmrc`** - указана версия Node.js
4. **Структура функций** - функции теперь в правильной структуре

## Важно для Netlify

Netlify **не поддерживает Flask напрямую** через обычный деплой. Для Flask приложений лучше использовать:

### Рекомендуемые альтернативы:

1. **Render.com** (лучший вариант для Flask)
   - Бесплатный тариф
   - Отличная поддержка Python/Flask
   - Автоматический деплой из GitHub

2. **Railway.app**
   - Простой деплой
   - Автоматическое определение Python проекта

3. **Heroku**
   - Классический вариант
   - Требует Procfile (уже создан)

## Если все же нужно использовать Netlify:

Netlify Functions требуют специальной настройки. Структура должна быть:

```
netlify/functions/server/
├── server.py
├── requirements.txt
└── __init__.py
```

И каждый function должен иметь свой `requirements.txt`.

## Быстрое решение - использовать Render

1. Перейдите на [render.com](https://render.com)
2. "New" → "Web Service"
3. Подключите GitHub репозиторий
4. Настройки:
   - Build: `pip install -r requirements.txt`
   - Start: `gunicorn app:app`
5. Готово!

Render автоматически определит Python проект и все заработает.
